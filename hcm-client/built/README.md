# hcm-client スタンドアロン配布パッケージ

本ディレクトリには、Host Credential Manager (HCM) の公式 CLI クライアントである `hcm-client` のビルド済みワンバイナリと起動支援スクリプトが含まれています。

Python、`fzf`、`sshpass` などの追加ツールをインストールすることなく、本パッケージ単体でターミナルから SSH および Telnet による対話型自動ログインが可能です。

---

## 📦 パッケージ同梱ファイル

- **`hcm-client`**: ビルド済みの単一実行バイナリ（Root CA証明書およびクライアント証明書を自己内包）。
- **`run.sh`**: サーバー接続用の起動スクリプト（デフォルト: `SERVER_IP=127.0.0.1`）。
- **`cert/cacert.pem`**: HCMサーバーのRoot CA証明書（バイナリにも埋め込まれています）。
- **`cert/client_cert.pem` / `cert/client_key.pem`**: mTLS用クライアント証明書・秘密鍵（バイナリにも埋め込まれています）。
- **`README.md`**: 本説明書。

---

## 🚀 基本的な使用方法

### 1. 起動スクリプト (`run.sh`) での実行（推奨）

最も手軽な起動方法です。実行権限が付与されていることを確認し、起動します：

```bash
chmod +x run.sh hcm-client
./run.sh
```

#### 別のサーバーIP / ホストに接続する場合
環境変数 `SERVER_IP`（または `SERVER_PORT`）を指定して実行します：

```bash
# 接続先サーバーのIPアドレスを指定
SERVER_IP=192.168.1.100 ./run.sh

# ポート番号も指定する場合
SERVER_IP=192.168.1.100 SERVER_PORT=8443 ./run.sh
```

#### 引数を渡して実行（一覧表示など）
`run.sh` は渡された引数をそのまま `hcm-client` に転送します：

```bash
# 登録済みターゲット一覧を表示して終了（接続テスト）
./run.sh --list

# ヘルプを表示
./run.sh --help
```

---

### 2. `hcm-client` バイナリを直接実行する場合

任意のオプションを直接指定して実行できます：

```bash
# デフォルト (https://127.0.0.1:8080) に接続
./hcm-client

# サーバーURLを明示的に指定
./hcm-client --url https://192.168.1.100:8080

# ターゲット一覧の確認
./hcm-client --url https://192.168.1.100:8080 --list

# 自己署名証明書の検証をスキップする場合
./hcm-client --url https://192.168.1.100:8080 --insecure
```

## 🖥️ 対話型 TUI の操作方法

`hcm-client` を実行すると、ターミナル上に高機能なインタラクティブ検索画面が立ち上がります：

1. **インクリメンタル検索**:
   キーボードから文字を入力すると、ホスト名・プロトコル（SSH/TELNET）・IP・ポート・ユーザー名・プラットフォーム（Linux, Cisco等）・タグを瞬時に複数ワードで絞り込みます。
2. **カーソル移動**:
   - `↑` / `↓` 矢印キー
   - `Ctrl + P` (上へ) / `Ctrl + N` (下へ)
3. **接続先決定**:
   - `Enter` キーを押すと選択中のホストが確定します。
4. **キャンセル・終了**:
   - `ESC` キー、または `Ctrl + C`
5. **マスターパスワード入力**:
   - 確定後、HCMサーバーのマスターパスワード入力プロンプト（画面上に文字は非表示）が表示されます。
   - 正しいパスワードを入力すると、暗号化保管されていた認証パスワードが取得され、SSH または Telnet の対話型セッションが自動的に起動します。
6. **セッション切断**:
   - SSH: `exit` または `Ctrl + D`
   - Telnet: `exit` または `Ctrl + ]`（エスケープ切断後に `quit`）

## 🔒 Mutual TLS (mTLS) と証明書の更新・失効について

- **ワンバイナリ mTLS**:
  本パッケージの `hcm-client` は、Root CA 証明書およびクライアント証明書が埋め込まれているため、追加の引数を指定することなく自動的に mTLS ハンドシェイクを行います。
- **サーバー側での CA 更新時**:
  HCM サーバー側で CA 証明書が再生成された場合、古いバイナリは TLS レベルで自動的に接続拒否されます。HCM Web UI から最新の `hcm-client.tgz` を再ダウンロードしてください。
- **証明書の失効時 (CRL)**:
  クライアント証明書がサーバー管理者によって失効（Revoke）された場合、接続は即座に拒否 (`tls: bad certificate`) されます。
